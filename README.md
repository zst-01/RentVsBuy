# 租买账：租房还是买房计算器

一个无需安装、在浏览器本地运行的租房与买房资产对比工具。填写房价、租金、首付、贷款和投资等假设后，可比较指定年限后的买房净资产与租房投资账户余额，并查看计算过程。

## 使用方法

1. 下载或克隆本仓库。
2. 在浏览器中打开 `index.html`。
3. 修改参数，结果会即时更新；点击“恢复示例”可还原示例参数。

无需安装依赖，也无需启动服务器。所有计算均在浏览器本地完成，输入数据不会上传。

## 可调整参数

- 房屋总价、建筑面积、家庭住房套数和每月租金
- 房价年涨跌幅
- 首付、契税、中介费和其他购房费用
- 贷款年利率与贷款年限
- 投资年化收益率和比较时间

页面会展示两种方案的期末资产、资产差额、房贷月供、剩余贷款、累计利息及购房费用估算，并提供公式和参数代入明细。

## 计算假设与限制

- 房贷按等额本息估算。
- 房租在比较期间保持不变。
- 租房方案将首付及购房费用作为初始投资，并按月投资月供与房租的差额；投资收益按年化收益率除以 12 计算。
- 契税默认值按页面说明中的北京面积和家庭住房套数规则预填。实际税费和中介费以当地政策及成交协商为准，可自行调整。
- 当前模型不计租金上涨、房屋持有成本、出售费用、通胀和投资税费。结果是基于输入假设的估算，不构成买房或投资建议。

## 文件

- `index.html`：页面结构与输入项
- `styles.css`：页面样式
- `calculator.js`：资产与贷款计算
- `app.js`：输入校验、参数联动和结果展示
